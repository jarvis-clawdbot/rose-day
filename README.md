# 🌹 Happy Rose Day - A Beautiful Romantic Website

A stunning, interactive website created to celebrate Rose Day with beautiful animations, heartfelt messages, and romantic surprises.

![Rose Day Website](https://via.placeholder.com/1200x630/dc2626/ffffff?text=Happy+Rose+Day)

## ✨ Features

### 🌹 **Interactive Landing Page**
- **Animated Rose Petals** - Falling petals create a romantic atmosphere
- **Floating Roses** - Beautiful 3D rose animations
- **Sparkling Text** - "Happy Rose Day" with animated letters
- **Rose Decorations** - Stunning rose designs on both sides

### 💌 **Romantic Letter Page**
- **Interactive Rose** - Click to reveal a heartfelt message
- **Falling Roses** - Continuous rose petal animation
- **Personalized Message** - Beautifully crafted romantic letter
- **Smooth Transitions** - Elegant page-to-page navigation

### ❤️ **Heart Garden Page**
- **Rose Garden** - Interactive garden of blooming roses
- **Heartfelt Messages** - Multiple romantic compliments
- **Rose Shower** - Continuous rose petal animation
- **Beautiful Layout** - Elegant card design with borders

## 🌹 Rose Day Significance

Rose Day is celebrated on February 7th as part of Valentine's Week. It symbolizes:
- **Love and Affection** - Expressing feelings through roses
- **Romance** - The beginning of romantic celebrations
- **Beauty** - Appreciating the beauty in relationships
- **New Beginnings** - Starting Valentine's Week with roses
